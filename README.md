# Selenium Automation using Java

## 1. Application Chosen : [https://demo.firefly-iii.org/](https://demo.firefly-iii.org/)

## 2. Framework and Language Used

- **Language:** Java
- **Automation Tool:** Selenium
- **Testing Framework:** Selenium

## 3. Add Libraries and Chrome Driver

- Add Chrome Driver Latest Version.
- Add the TestNG libraries
- Add the Java standalone server version **3.141.59**

## 4. How to run the tests (setup steps)

- **Open the test class (e.g., "TC_001.java")**
- **Right-click on the file**
- **Select Run As → Java Application**

## 5. Test Case Used from Task 1

- Positive Scenario: **TC_001**
- Negative Scenario: **TC_005**
